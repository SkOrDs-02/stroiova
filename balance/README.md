# Баланс економіки

`sim.js` — модель-еталон економіки «Стройової» (конституція, принцип II). Чисті функції без DOM, ES5, детермінована (seed). Дохід = min(сума потоків, найвужча ланка) × множники. Віртуальний гравець заходить 5 разів на день по 4 хв, купує те, що найшвидше окупається, цифровізується, коли застряг, проходить перевірки й гонки. Три сценарії: з рекламою, без реклами, платний («Без реклами» + стартовий набір).

## Версії

| Версія | Що додала | Пресет |
| --- | --- | --- |
| v3–v4 | потоки + труба, цифровізація | (поля без пресета) |
| v5 | «Бригада», генератор, офлайн ×2 за рекламу, сповільнення телеграм | `preset-v5.json` |
| v6 | події: Пташка, архів, Кіт, «Комбата шукають», перевірки, подарунки й гонка, стартовий набір, музей, папір | `preset-v6.json` |
| v7 | рівні 1–5 (`levels[]`), вихід з рівня через N цифровізацій і підсумкову перевірку, пачки телеграм Р3, «Звіти про звіти» Р4, цифрові ланки Р5, фінал; «Нарада затягнулась», «Збій СЕДО» | `preset-v7.json` |

Старі пресети вантажаться через `withDefaults()`: нові механіки вимкнені, результат той самий, що й у версії, де пресет збережено (v3–v6 перевірено побітово на 3 зернах × 3 сценаріях).

## Як запустити

```sh
node -e "var S=require('./balance/sim.js'); var r=S.simulate(S.DEFAULTS, S.SCENARIOS[1]); console.log(S.levelStats(r))"
python3 balance/sandbox/build.py   # пісочниця → balance/sandbox/index.html (у .gitignore)
```

`levelStats(r)` повертає дні входу в рівні, оголошення підсумкових, фіналу й середній проміжок між цифровізаціями на кожному рівні. Модель зупиняється на фіналі (6-та конвертація на Р5); нескінченний режим не моделюється.

## v7: параметри рівнів

| Рівень | Виробіток / ціни / діловоди | Ріст ціни × | Дільник балів | Вихід |
| --- | --- | --- | --- | --- |
| Р1 «Батальйон» | ×1 / ×1 / ×1 | 1 | 75 000 | 3-тя цифровізація |
| Р2 «Бригада» | ×10 / ×5 / ×1 | 0,45 | 6,27·10⁹ | 4 + підсумкова |
| Р3 «Командування» | ×100 / ×25 / ×1 | 0,45 | 6,76·10¹¹ | 6 + підсумкова |
| Р4 «Генштаб» | ×1 000 / ×125 / ×1 | 0,45 | 2,29·10¹³ | 6 + підсумкова |
| Р5 «Армія без паперу» | ×10 000 / ×625 / ×1 | 0,35 | 9,01·10²² | 6 конвертацій → фінал |

«Ріст ціни ×» стискає ріст ціни рівнів (1,12 → 1,054 при 0,45). Без цього цикл триває ≈ 1 день за будь-якого дільника: підказка «наступна покупка далі ніж за 4 год» (рішення 2) настає раніше, ніж гравець збере на довший цикл, і довший цикл виходить лише простоєм.

- Між цифровізаціями (з рекламою): Р2 2,1–2,3 дн, Р3 2,7–3,1, Р4 2,7–2,9, Р5 3,9–4,4 (цикли Р5 скорочуються з ≈ 5 до ≈ 3 днів). Найдовше очікування покупки 14–27 год (ціль 12 год не тримається: ніч між сесіями сама 11,2 год).

- Підсумкові перевірки проходять з першої спроби в усіх 3 сценаріях. «Звіти про звіти»: 13% потоків на вході в Р4, 57–60% перед «Аудитом усього».
- Ранні віхи v6 (перший діловод 3,42 хв, перша цифровізація, «Бригада») не змінилися: рівень 1 не чіпали.
