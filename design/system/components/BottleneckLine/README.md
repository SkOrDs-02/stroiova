# BottleneckLine

Рядок між блоками «Потоки» й «Погодження», який показує, що зараз обмежує дохід.

**Що передає споживач:** суму потоків за хвилину, швидкість найвужчої ланки, назву найвужчої ланки або «потоки», і чи стоїть ланка (з часом).

**Стани:** вузько в погодженнях; вузько в потоках; рівно; ланка стоїть.

**Правила**

- Перший рядок — числа: «Потоки 1 200/хв → Погодження 412/хв». Вужчу сторону виділяємо кольором `accent` і підкресленням.
- Другий рядок — висновок словом: «Вузько: Резолюції комбата», «Вузько: потоки — відкрийте або покращте потік», «Рівно», «Стоїть: Резолюції комбата, ще 18 хв».
- На екрані 390 це завжди два рядки. На ширшому екрані висновок може стати в один рядок через « · ».
- Фон `bg-deep`, числа `num` 600, швидкість пишемо як «412/хв».

**Доступність:** увесь рядок читається однією фразою («Потоки 1 200 за хвилину, погодження 412 за хвилину. Вузько: Резолюції комбата»). Вузьку сторону видно з підкреслення й слова, не лише з кольору.
