# BottomSheet

Каркас шторки знизу. На ньому зроблено дванадцять шторок гри: деталі потоку чи ланки, множники, ресурс, репутація, «Комбата шукають», меню, свій позивний, «Це не смішно», записка, експонат.

**Що передає споживач:** заголовок (`h2`), підзаголовок, необов'язкову плашку іконки, вміст, закріплену внизу дію (`Button` `primary` `l`), обробник закриття.

**Правила**

- Фон шторки `bg`, верхні кути `radius-12`, верхній край — лінія `shadow-sheet`. Під шторкою — затемнення `scrim` (шар `z-sheet`).
- Ручка 36×4 кольору `border` по центру, поля 16.
- Шапка: плашка іконки, заголовок і підзаголовок, кнопка закриття 44×44.
- Висота не більше 88% екрана. Довгий вміст скролиться, а дія лишається внизу.
- Пари «назва — значення» мають підпис `muted`, а значення — Plex Mono 600.
- Шторка виїжджає за `dur-sheet` з `ease-out`. З Reduce Motion — проявляється на місці.

**Доступність:** шторка модальна (`accessibilityViewIsModal`), фокус переходить у заголовок. Закрити можна кнопкою, свайпом і системною дією «назад» (escape).
