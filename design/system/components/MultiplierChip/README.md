# MultiplierChip

Чип загального множника в шапці головного екрана. Тап відкриває шторку «Множники».

**Що передає споживач:** сумарний множник, підпис (таймер, кількість джерел, «назавжди», «12 год · межа»), тип (тимчасовий чи постійний).

**Правила**

- Рамка `accent`, радіус `radius-8`, множник Plex Mono 15/600 («×2», «×6»), підпис `num-s` під ним. Висота щонайменше 44.
- Постійний множник («×1,5 назавжди» за «Без реклами») має рамку `border` і текст `text`.
- Буст накопичується щонайбільше до 12 год, тоді підпис каже «12 год · межа», а кнопка буста в шторці неактивна.
- Множники пишемо з комою: «×1,5», «×2,04».

**Доступність:** `accessibilityLabel` повною фразою: «Разом ×6 з чотирьох джерел. Відкрити множники».
