# Banner

Банер у потоці головного екрана: перевірка з таймером, «не встигаєте», підказка цифровізуватися, стан ресурсу, переповнене сховище.

**Що передає споживач:** іконку, текст (до 2 рядків), значення таймера, підпис дії і тон (`alert`, `accent`, `neutral`). Тап по всьому банеру виконує дію.

**Правила**

- `alert` — лише справжня тривога з часом: фон `alert-bg`, рамка `alert-line`, текст `alert-text`, таймер Plex Mono 600. Завжди з іконкою й словом.
- `accent` — порада гри: рамка 1,5 px `accent` («Наступна покупка — через 6 год. Час цифровізуватися.»).
- `neutral` — стан без загрози: фон `surface` і дія кольором `accent` («Пальне скінчилося: бонус ×1,25 вимкнено · Заправити»).
- Висота щонайменше 44, радіус `radius-10`. Справа — дієслово дії зі стрілкою.

**Доступність:** банер — одна кнопка з повною фразою, таймер читається словами («Перевірка через 2 години 14 хвилин»).
