# TelegramCard

Картка телеграми чи записки у вкладці «Телеграми».

**Що передає споживач:** номер, штамп терміновості (необов'язково), статус, заголовок, мета (від кого, строк, наслідок), тип (`telegram` чи `note`), обробник.

**Стани:** нова; на виконанні (таймер); у шухляді; відповіли (архів, штамп «ВИКОНАНО»); записка.

**Правила**

- Нова має рамку 1,5 px `accent` і слово «нова» з крапкою. Лічильник нових — у таб-барі.
- Заголовок `body-l` 500 в один рядок із трикрапкою. Повний текст — на екрані телеграми.
- Штамп — `Stamp` розміру S кольору `stamp-on-dark`.
- Архів має фон `surface-2`.
- Порожній список: «Телеграм немає. Підозріло.»

**Доступність:** картка — одна кнопка. Статус написаний словом. Штамп читається як текст («Терміново»).
