# ChecklistRow

Рядок чекліста підготовки до перевірки: пункт, ціна в підписах, позначка виконання.

**Що передає споживач:** назву, пояснення, ціну, стан (`todo`, `done`, `short` — не вистачає) і скільки бракує, обробник.

**Правила**

- Рядок заввишки `row-check` (58), чекбокс 24 з рамкою 2 px `accent` і радіусом 6. Виконаний — заливка `accent` з галочкою `accent-ink`.
- Виконаний пункт закреслено, назва стає `muted`.
- Не вистачає підписів — рамка чекбокса `border-strong`, під ціною «бракує 62 тис.».
- Пункти — про тумбочки, бордюри й кегль: «Пофарбувати бордюри», «Відкрити буржуйку», «Підшити журнали». Бойову підготовку комісія не перевіряє.

**Доступність:** `accessibilityRole="checkbox"` з `checked`. Виконання видно і з галочки, і з закреслення.
