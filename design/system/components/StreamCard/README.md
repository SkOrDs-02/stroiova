# StreamCard

Картка потоку документів (Рапорти, Акти на майно, Довідки, Накладні; на рівні 2 — Накази по частині) у блоці «Потоки» головного екрана.

**Що передає споживач:** назву, іконку, рівень, швидкість («+120/хв»), діловода (ім'я й прізвисько) або його відсутність, прогрес до віхи (0–100), ціну покращення й доступність, обробник тапу по картці (відкриває шторку `unit-sheet`) і по кнопці.

**Стани:** замкнено (немає грошей / можна відкрити); вручну, без діловода; з діловодом; перед віхою; не вистачає підписів.

**Правила**

- Рядок: плашка іконки `icon-plate` на `border`, назва `body` 500 в один рядок, трек `track-s` до наступної віхи (кожні 25 рівнів — ×2), мета `caption` з рівнем `num-s`.
- Кнопка праворуч: покращення — заливка `accent` зі стрілкою і ціною `num`; найм — обведена `accent` у два рядки («найняти / 2,4 тис.»); не вистачає — рамка `border`, ціна `muted` і час «ще 2 хв» під нею.
- Без діловода мета каже «лише поки ти в грі». З діловодом — його ім'я: «діловод Петро «Швидкозшивач»».
- Перед віхою — тег «×2 на 25-му».
- Замкнена картка має фон `surface-2`, пунктирну рамку й замок; опис каже, що потік дає.
- Ціни показуємо компактно й округлюємо вгору (див. «Формат чисел»), щоб не обіцяти покупку, на яку не вистачає.

**Доступність:** кнопка ≥ 44×44, її `accessibilityLabel` містить дію й ціну («Покращити рапорти за 186 тисяч підписів»). Недоступна кнопка пояснює причину. Стан словом, не лише кольором.
