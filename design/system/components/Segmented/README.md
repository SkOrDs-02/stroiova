# Segmented

Перемикач з 2–3 варіантів: кількість покупки в шторці («×1 / ×10 / до віхи») і фільтр музею («Усі / Майно / Особовий склад»).

**Що передає споживач:** варіанти, вибраний варіант, обробник, `accessibilityLabel` групи.

**Правила:** кожен сегмент — пігулка `radius-pill` заввишки 44. Вибраний має заливку `accent` і текст `accent-ink` жирним, решта — рамку `border` і текст `text`. У шторці сегменти ділять ширину порівну, числа набрано Plex Mono.

**Доступність:** у групи `accessibilityRole="radiogroup"`, у сегмента — `radio` з `accessibilityState={{ selected }}`. Вибір видно з заливки й жирного тексту, а не лише з кольору.

Додано понад список карти екранів: є в мокапі музею й потрібен у шторці потоку.
