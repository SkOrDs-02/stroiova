# Button

Кнопка дії на темному спорядженні або на папері.

**Що передає споживач:** підпис (≤ 22 знаки), варіант (`primary`, `secondary`, `neutral`, `quiet`, `paper`), розмір (`l` 56, `m` 48, `s` 44), необов'язкові іконку, ціну (`num`), підпис під кнопкою і причину недоступності.

**Варіанти**

- `primary` — заливка `accent`, текст `accent-ink`. Одна на екран: головна дія («Прибути в частину», «Оцифрувати», «Забрати ×2 · 372 800»).
- `secondary` — рамка 1,5 px і текст `accent` («Далі», «Дивитися»).
- `neutral` — рамка `border`, текст `text`. Друга дія під головною («Забрати 186 400», «Не зараз»).
- `quiet` — підкреслений текст `muted` для посилання в документі («Сховище тримає 8 год. Розширити»).
- `paper` — на аркуші: рамка `ink`, Plex Mono («Прискорити»). Головна дія на аркуші — заливка `accent`.
- Недоступна — рамка `border`, текст `muted`, під кнопкою причина: «Ще 8 балів до мінімуму в 30.»
- Іконкова — 44×44, радіус `radius-10` (меню, назад, закрити).
- Тап-печатка `seal-tap` 132 px — лише перший акт онбордингу.

**Доступність:** висота щонайменше `touch-min`. Іконкова кнопка завжди має `accessibilityLabel`. Недоступна кнопка — `accessibilityState={{ disabled: true }}`, а причина написана текстом поруч. Фокус — `focus-ring`, на папері `focus-ring-paper`.
