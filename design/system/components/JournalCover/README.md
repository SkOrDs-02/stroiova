# JournalCover

Обкладинка скасованого журналу в музеї: картон, прошивка суровою ниткою, паперова етикетка, штамп «СКАСОВАНО».

**Що передає споживач:** колір обкладинки (`cover-*`), перше слово назви («Книга», «Журнал», «Стелажні»), решту назви, рідкість, бонус; для незнайденого — звідки випадає.

**Стани:** звичайний, рідкісний, легендарний, не знайдено.

**Правила**

- Обкладинка `cover-height` (110) з радіусом `radius-4`. Ліворуч — прошивка пунктиром `paper-4`.
- Етикетка — `paper` з текстом `ink` Plex Mono 12: перше слово жирним капсом, далі не більше трьох рядків назви з трикрапкою. Повна назва з наказу — у шторці експоната.
- Штамп «СКАСОВАНО» — `Stamp` S кольору `stamp-on-dark`, у правому нижньому куті, не на етикетці.
- Рідкість словом: «Звичайний» (`rarity-common`), «Рідкісний» (`rarity-rare`), «Легендарний» (`rarity-legend`, рамка картки 2 px і зірка). Під словом — бонус.
- Незнайдений: фон `surface-2`, пунктир, замок, «???», джерело: «Випадає з телеграм».
- У MVP лічильник колекції — «з 8».

**Доступність:** картка — кнопка з повною назвою журналу й рідкістю в `accessibilityLabel`. Рідкість названо словом.
