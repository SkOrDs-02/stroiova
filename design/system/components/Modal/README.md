# Modal

Каркас модального вікна у двох варіантах: спорядження (питання, підтвердження) і документ (результат на аркуші).

**Що передає споживач:** заголовок, текст, вміст, головну й другу дії, варіант `gear` чи `paper`.

**Правила**

- Варіант `gear`: фон `bg`, рамка `border`, радіус `radius-12`, поля 20/16. Використовуємо для незворотної дії: «Оцифрувати батальйон?» — що обнулиться, що залишиться, «Оцифрувати» і «Не зараз».
- Варіант `paper`: аркуш з жорсткою тінню `shadow-stack` і штампом, кнопка під аркушем. Так показуємо результати: «Зараховано», акт перевірки, «Пташка в небі», «Списано раніше, ніж поставлено на облік».
- Затемнення `scrim`, шар `z-modal`. Одна головна дія.
- Модалка не закривається тапом по затемненню, якщо в ній незворотна дія.

**Доступність:** модальна область, фокус на заголовку. Кнопки ≥ 44 px. Результат, показаний штампом, продубльовано текстом («×1,5 уже діє»).
