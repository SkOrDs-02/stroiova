# NumberFormat

Правила виводу чисел, часу, швидкості, цін і множників. Прев'ю — живий форматер.

**Великі числа**

- До 10 000 — повне число з нерозривним пробілом: «4 120».
- Далі — 3 значущі цифри й скорочення: «186 тис.», «2,41 млн», «12,5 млн», «999 млрд». Після млрд ідуть літери: «aa» = 10¹², «ab» = 10¹⁵ … «az», «ba» і так далі («12,3 ab»).
- Якщо округлення дає 1000, переходимо на наступний розряд: 999,99 млрд → «1 aa».
- Лічильник у шапці до 10 млн показує повне число («1 248 360»), далі — два знаки після коми («12,48 млн», «999,99 млрд»).
- Баланс округлюємо вниз, ціну — вгору. Так кнопка ніколи не показує ціну, на яку насправді не вистачає.
- Десятковий знак — кома. Між числом і одиницею — нерозривний пробіл.

**Час, швидкість, гроші**

- Тривалість: «38 с», «42 хв», «5 год 12 хв», від двох діб — «2 дн 3 год». Гонка з часом — реальний час, без «днів».
- Відлік: «02:14:37» для таймера перевірки, «ще 3:41:12» у чипі.
- Швидкість: «+412/хв».
- Ціна: «199 ₴» Plex Mono, з нерозривним пробілом.
- Множник: «×1,5», «×2,04». Відсоток: «+35%», «62%».

Великі числа в коді — break_infinity.js. Форматер — одна функція в модулі економіки, спільному з симулятором.
