# ResourceTile

Плитка ресурсу в шапці головного екрана: папір, генератор (пальне), репутація. Тап відкриває шторку ресурсу.

**Що передає споживач:** іконку, значення, підпис, стан і `accessibilityLabel` повною фразою. Три плитки стоять сіткою по третині ширини (≈ 111 px на екрані 390).

**Стани**

- Генератор: бонус діє (бак понад 20%: рамка `accent`, підпис «×1,25»); менше 20% («без бонусу»); порожньо («заправити» кольором `accent`). Пальне — бонус, а не штраф: порожній бак означає звичайну швидкість.
- Папір: запас («4 120 аркушів»); нуль. Конвеєр через папір не зупиняється, папір потрібен лише телеграмам і спецдокументам.
- Репутація: «низька», «норма», «висока» — словом і стрілкою індикатора (`gauge-low`, `gauge-mid`, `gauge-high`). Плитка репутації стоїть на місці тонера: тонер у MVP не входить.

**Правила:** значення `num` (Plex Mono 13) не довше 8 знаків — «5 год», «65 хв», «4 120», «порожньо». Підпис — `caption` (12 px), не довше 10 знаків. Довший опис живе у шторці.

**Доступність:** плитка — кнопка ≥ 44 px заввишки. `accessibilityLabel` повною фразою: «Генератор: ще 5 годин, бонус ×1,25».
