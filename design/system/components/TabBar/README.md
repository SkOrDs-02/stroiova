# TabBar

Нижня навігація з п'ятьма вкладками: Стройова, Телеграми, Цифра, Музей, Магазин.

**Що передає споживач:** активну вкладку, лічильник нових телеграм, позначки «рекомендовано» на Цифрі й «новий експонат» у Музеї, обробник.

**Правила**

- Фон `bg-deep`, верхня лінія `border`. Вкладка заввишки `tab-height`, іконка 22 зі штрихом 1,8, підпис `label` (11 px).
- Активна вкладка — `accent`, неактивна — `muted`.
- Лічильник — бейдж `alert` з цифрою `on-alert`; понад 9 — «9+». Позначка без числа — крапка 8 px кольору `accent` з обвідкою `bg-deep`.
- На онбордингу таб-бар прихований до кроку 6. На екранах із кнопкою «Назад» (телеграма, перевірка) його немає.

**Доступність:** `accessibilityRole="tab"` і `selected`. Лічильник і позначки читаються словами: «Телеграми, нових: 3», «Цифра, рекомендовано».
