# Toast

Коротке повідомлення внизу екрана над таб-баром: подія, нагорода, кіт, помилка.

**Що передає споживач:** текст (≤ 60 знаків, щонайбільше 2 рядки), іконку, тон (`event`, `muted`, `fail`), необов'язкову дію («Відкрити»).

**Правила**

- Фон `surface`, рамка `border`, жорстка тінь `shadow-stack`, радіус `radius-10`, шар `z-toast`.
- Іконка `accent` для подій і нагород, `muted` — для нейтральних, `fail` разом зі словом — для помилок («Покупка не пройшла. Гроші не списано.»).
- Тримається `dur-toast` (з дією — 6 с). Одночасно — один тост, решта в черзі.
- Тексти — з банку рядків: «Віху взято: рапорти йдуть удвічі швидше.», «Ролик закрито раніше. Нагороди немає, спроба не згоріла.»

**Доступність:** `accessibilityLiveRegion="polite"` (Android) або оголошення через `AccessibilityInfo.announceForAccessibility` (iOS). Помилку видно зі слова й іконки, а не лише з кольору.
