# Icons

Контурні іконки 24×24 зі штрихом 1,8, круглими кінцями й з'єднаннями, без заливки. Файли намальовано одним чорнилом #B5B39F (`muted`, як неактивна вкладка), щоб їх було видно в галереї. У грі через react-native-svg ставимо `stroke="currentColor"` і фарбуємо токеном: `text`, `muted` або `accent`. Штрих 2,0 — для дії в кнопці, 2,2–2,4 — для стрілок і галочок на заливці.

Скопійовано з мокапів:

- `doc.svg` — вкладка «Стройова», потік «Довідки».
- `envelope.svg` — вкладка «Телеграми», тост нової телеграми.
- `chip.svg` — вкладка «Цифра», кнопка «Оцифрувати».
- `archive.svg` — вкладка «Музей», ланка «Стройова частина», сховище.
- `bag.svg` — вкладка «Магазин».
- `report.svg` — потік «Рапорти».
- `resolution.svg` — ланка «Резолюції комбата».
- `cash.svg` — ланка «Фінслужба».
- `layers.svg` — ресурс «Папір».
- `bolt.svg` — генератор і пальне, буст.
- `printer.svg` — принтер «Дід».
- `clock.svg` — таймер, перевірка, акт у дорозі.
- `drone.svg` — «Пташка», цивільний квадрокоптер без підвісу.
- `pen.svg` — «Підписати».
- `play.svg` — реклама за винагороду, «Прискорити».
- `arrow-up.svg` — покращити.
- `arrow-right.svg`, `arrow-left.svg` — далі, назад.
- `check.svg` — виконано, нагороду зараховано.
- `menu.svg` — меню.
- `star.svg` — легендарний журнал.
- `lock.svg` — замкнено, не знайдено.
- `cup.svg` — Кіт Сейф у тості, заглушка аватара «Кави».

Домальовано на тій самій сітці, бо в мокапах їх не було:

- `close.svg` — закрити шторку чи модалку.
- `warning.svg` — помилка й термінова тривога (завжди разом зі словом).
- `gauge-low.svg`, `gauge-mid.svg`, `gauge-high.svg` — репутація «низька», «норма», «висока». Стан видно з положення стрілки, а не лише з кольору.
- `seal.svg` — порожня кругла печатка, мотив іконки застосунку.
