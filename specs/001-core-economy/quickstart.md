# Перевірка: 001 Економіка ядра й офлайн

## Передумови

`npm install` (у хмарній сесії робить хук), Node 22, Python 3 з `jsonschema`.

## 1. Модуль і симулятор — один код (AC-1, принцип II)

```sh
npm run build:economy              # src/economy/core → balance/economy.js
npm test -- src/economy/__tests__/golden-test.ts
```

Очікувано: відбитки `simulate`, `levelStats`, `eventStats` для preset-v5/v6/v7 × зерна 1–3 × 3 сценарії збігаються з `balance/golden/fingerprints.json` (знятими з sim.js до рефакторингу); preset-v5, «Дивиться рекламу»: перший діловод 3,07 хв, перша цифровізація 3,13 дня, «Бригада» 7-й день.

## 2. Формули й правила (AC-2 … AC-21)

```sh
npm test -- src/economy
```

Кожен AC — окремий `test()` з номером у назві (`AC-7: …`), фікстура — preset-v5 (рішення 52). AC з UI-станами, яких немає в зрізі, перевіряють доменну частину (числа, події); екрани — 002.

## 3. Чистота ядра

```sh
npm run lint
```

Очікувано: правила для `src/economy/**` не пускають `react`, `react-native`, MMKV, `Date.now`, `Math.random`.

## 4. Пісочниця

```sh
python3 balance/sandbox/build.py && xdg-open balance/sandbox/index.html
```

Очікувано: сторінка будується з `economy.js` + `sim.js`, графіки й віхи ті самі, що до рефакторингу.

## 5. Вертикальний зріз у застосунку

```sh
npm start   # або npx expo export --platform web і відкрити в браузері
```

Сценарій:
1. Екран «Конвеєр»: Рапорти 1-го рівня, ланки 1-го рівня, решта потоків замкнена.
2. Тапнути печатку кілька разів → баланс росте на `tapValue` × M; швидкі тапи обрізаються до 10/с.
3. Купити Рапорти ×1, ×10, «до віхи», коли вистачає; рядок «Потоки … → Погодження … · Вузько: …» оновлюється.
4. Найняти діловодів на Рапорти й три ланки → застосунок у фон на ≥ 5 хв → повернення показує довідку з сумою; без діловодів — «Стройова стояла».
5. Відкрити Акти → наступний потік стає доступним.

npm run check
