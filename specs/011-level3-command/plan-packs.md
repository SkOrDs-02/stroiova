# Implementation Plan: 011 Вихід з «Бригади» і рівень 3 - етап 2 (пачки)

**Branch**: `011-packs` (від `main` після PR #17) | **Date**: 2026-10-19 | **Spec**: [spec.md](spec.md) | Продовження [plan.md](plan.md)

## Summary

Телеграми Р3 приходять пачками по три о 03:00; відповісти можна окремо або «Звести в одну відповідь» (менше паперу й репутації, один ризик, сповільнення «Нарада» і баф «Зведення б'ється»). Підсумкова Р3 «Перевірка зі столиці» перевіряє, що остання пачка закрита сумлінно.

## Обсяг

| FR | Етап 2 |
| --- | --- |
| FR-17, FR-18 | доставка о 03:00, мішок із 20 пачок, один рядок у «Нових», окрема телеграма дня Р3 |
| FR-19, FR-20 | `tg-pack`: обкладинка, три картки, «Звести в одну відповідь», прогноз поруч із сумою окремих, неактивний вид з `pack.no_kind` |
| FR-21, FR-22 | ефекти зведеної відповіді, «Зведення б'ється» |
| FR-23 | «Новий наказ скасовує старий» - не в пачці (пул без `pack`, слот окремої) |
| FR-24 | `tg-result` зведеної відповіді, один запис курйозів на пачку |
| FR-27, FR-28 | підсумкова Р3 з `summary_beats`; перехід на Р4 - 012 |
| FR-29, FR-30 | схема 11, міграція 10 → 11; тест контенту пачок |

AC: 11-16, 18, 20. Поза етапом: `push.boss` (пуш для підсумкової), журнал серії (016), `unit-unlock`/`coach` Р3, діловоди (рішення 97).

## Project Structure

```text
src/telegrams/packs.ts       пачки: видача, стан, прогноз, зведена відповідь, закрито сумлінно
```

Поза етапом: індикатор «Зведення б'ється» на `main` (є тост і фактор у шторці множників); негативні тести `gen_tg.py` для пачки (CI перевіряє валідний файл).
