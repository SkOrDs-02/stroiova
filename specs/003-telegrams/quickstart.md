# Quickstart: 003 — етап 1

```bash
npm run check
python3 tools/check_content.py
```

Web-сценарій (Chromium 375×667, `page.clock`):
1. Пройти онбординг до кроку 8 → № 1 у «Нових», відповідь «сумлінно» → «На виконанні» з таймером, репутація 60 на плитці.
2. Годинник +10 год (гра закрита) → 2+ нові телеграми з мітками слотів, ≤ 5 нових.
3. Відписка → репутація −5; шанс перевірки не показано (до першої планової, FR-15).
4. Шухляда → «Шухляда · 1»; відповідь звідти.
5. Плитка репутації → шторка: рівень і 3 останні зміни.
6. Варіант з папером при нестачі — неактивний «Бракує N аркушів».
7. «Це не смішно» → форма → «Позначено».
8. Новий день, старт сесії з подією «Комбата шукають» → `kombat-sheet`, «Відправити посильного» → через 3 хв «знайшли».
