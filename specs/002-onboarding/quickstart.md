## Web-сценарій (Chromium 375×667, `page.clock`)

1. Порожнє сховище → `onb-title` (без системних вікон) → «Прибути в частину» → `onb-intro`.
2. «Пропустити» → `onb-callsign`: «Ексель» обрано, стать порожня; «Записати чорною пастою» → o3.err3.
3. «Вписати свій позивний»: «зсу-1» → o3.err4; «Сисадмін», «Вона · прибула» → крок 3 закрито.
4. 8 тапів «Підписати» (11 тапів → зараховано 8) → ПОГОДЖЕНО, «Пташка в небі», o4.comment «Цього разу встигла…» → «До стройової».
5. `main`: лише Рапорти й 3 ланки, таббар; коуч на кнопці покращення; тап поза нею нічого не робить; покупка.
6. Чекати (тапати печатку), поки підписів ≥ ціни діловода Стройової → коуч найму → `clerk-first` → «Далі» → тост b7.toast.
7. Ігровий час 300 с → тост b8.toast, бейдж «1», коуч на вкладці → `tg-detail` → вибір → `tg-result` «перший раз».
8. Ігровий час ≥ `archiveBonusAtSec` → `call`: виклик → репліки → бонус, тост b9.toast.
9. Перезавантажити сторінку на кроці 4 → акт «0 з 8», позивний на місці.
10. Годинник сторінки +1 год на 4:00 → телеграма не прийшла раніше 5:00 ігрового часу.
