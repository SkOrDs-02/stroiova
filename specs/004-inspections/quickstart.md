```bash
npm run check                    # типи, лінтер, тести, тема, контент
node tools/golden.mjs --check    # 27 відбитків не змінились
npx jest src/inspections         # домен
```

## Web-сценарій (Chromium 375×667, `page.clock`)

1. Онбординг до кінця, гра відкрита о 09:00. Перевести годинник на 18:00, нова сесія → `call` з `call.insp1` → `insp-warning` «перший раз», відлік 2–3 год (AC-1).
2. «Готуватися» → `insp-prep`: 5 пунктів, ціни = хвилини × дохід, недоступний пункт «бракує N · ще T» (AC-7, AC-8).
3. Купити всі пункти → 100%; дочекатися приїзду в грі → `insp-result` «пройшли», ×3 у чипі множника (AC-10).
4. Перемотати 24–48 год з закритою грою до наступної планової й приїзду → довідка з рядками перевірки (AC-15, AC-16).
5. Наступна планова при відкритій грі → лише банер, тап відкриває `insp-prep` (AC-3).
6. Відписка на телеграму з шансом, випадок спрацював → `insp-warning` «позапланова» з причиною (AC-5).

Очікування: жоден крок не обнуляє дохід; після провалу «Стройова частина» ×0,5 на 1 год (AC-11).
