# Стройова (Stroiova)

Мобільна idle-гра для iOS і Android: сатира на армійський документообіг. Гравець проштовхує папери крізь бюрократію, щоб бійці отримали дрони, відпустки й поставки, а у фіналі переводить армію на цифру.

Статус: дизайн і специфікації готові, код ще не почато. Розробка за специфікаціями (GitHub Spec Kit) — див. `CLAUDE.md` і `.specify/memory/constitution.md`.

- План: `docs/roadmap.md`
